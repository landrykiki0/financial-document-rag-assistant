# Financial Document RAG Assistant

Chatbot RAG pour analyser des documents financiers en langage naturel.

## Fonctionnalités
- Upload de plusieurs PDFs simultanément
- Chat avec mémoire de conversation
- Réponses contextualisées basées sur les documents

## Technologies
Python, LangChain, OpenAI API, FAISS, Streamlit, PyPDF2

## Installation
pip install -r requirements.txt

## Configuration
Créer un fichier .env :
OPENAI_API_KEY=ta_clé_ici

## Lancement
streamlit run app.py
